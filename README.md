### NC15FF vs NC10FF: pick based on your cart, not the percentage

The 15% code looks like the obvious winner until you read the per-item minimum. NC15FF applies to **each individual item**, not the cart total. Saudi shoppers need each item to clear SAR 550, UAE shoppers AED 550, and US coverage puts the per-item floor somewhere around $100–$200 depending on market.

That means a cart with an $800 coat and two $120 accessories earns 15% on the coat only. Two accessories below the threshold get nothing, no matter how large the total order is.

NC10FF on the app has a lower or nonexistent stated minimum in several markets, so if you're buying several smaller pieces, the 10% app code can beat the 15% website code. If you're buying one designer bag that comfortably clears the minimum, NC15FF wins.

Both are once-per-account. If there's any completed order on your account history, neither will apply again.

### Cardholder codes are the most reliable of the bunch

The Mastercard offers are the rare Farfetch discounts published by the party paying for them, which makes them stable and checkable. FFMC2026 gives 10% off full-price items with a minimum spend of around US$300, capped at four redemptions in a calendar year, listed as running to 31 December 2026. It excludes certain brands — the exclusion list is published as a document alongside the offer — and can't be combined with other promotions.

The catch is eligibility. These run through specific issuing banks and regions, so check your own card's offers portal before assuming you qualify.

## The promo field is not where you think it is

This trips up first-time Farfetch shoppers more than any code problem does. The promo code field is not on the bag page and not at the top of checkout.

Standard flow:

1. Sign in to your Farfetch account before you shop — being logged in activates your Access tier and any account-specific offers.
2. Add full-price items to the bag and confirm each one individually clears the minimum if you're using a first-order code.
3. Go to checkout and enter your delivery address.
4. On the payment screen, find the promo code field. Multiple write-ups place it on the right-hand side of the payment step, after the address, before card details. Some markets show it under the order summary instead, so scan the whole page.
5. Type the code exactly as given — these are case-sensitive — and hit Apply. The total updates immediately.
6. Only then enter payment details.

One code per order. If you're testing a second code, remove the first, or the field will reject the new one.

## Why your farfetch promo code isn't applying

Almost every unexplained failure lands in one of these buckets:

- **Brand exclusions.** Gucci, Fendi, Prada and Miu Miu are excluded across the board on most offers, and New Season collections are frequently excluded too. Fine Watches are excluded from essentially every Farfetch promotional code, platform-wide.
- **The per-item minimum.** Covered above, but it's the single most common cause of a code that "doesn't work" on a big cart.
- **Sale items in the bag.** First-order and cardholder codes generally apply to full-price only. Sale items sit out.
- **The code is one-use.** First-order codes are gone once your account has any completed order.
- **An account-targeted code.** Some codes are dropped onto specific accounts rather than published. If you didn't receive it, it won't work for you.
- **The campaign ended.** Aggregator pages routinely keep expired codes up for months.

If a code fails and you can't match it to any of these, try the same code on a different eligible item before assuming it's dead. The code is usually fine; the cart is the problem.

No. One promotional code per order, and you need to remove an existing code before applying a new one.

**How long until cashback is withdrawable?**

Usually not. First-order and cardholder codes are full-price-only. The exception is sitewide codes like HONEYY325, which apply to some reduced items — check the item page before assuming.
